# 收录规则

核验日期：2026-10-15（Asia/Shanghai）。这一版只覆盖李政道研究所。人数会随官网变化，下面的 27 是当天天文部基线，不是永久常数。

## 收谁

- 天文与天体物理研究部的学者系列、研究员系列，以及写明双聘的人，全部收录。
- 其他研究部里，官方任职或研究方向原文明确涉及天文、宇宙学、天体粒子、暗物质、中微子之一的教师，收录，并记下原文。
- 博士后、访问学者、工程师、行政和科研助理不收。平台学者名录的主聘不在三个研究部，这一版不收。
- 退休单独记录，默认名录只显示现任。兼职和双聘保留原文，并用角色标出来。
- 只写「粒子物理」或「对撞机物理」不够。个人页或导师名单写明暗物质、中微子、宇宙学、天体粒子、黑洞或引力波，才按跨部规则收录。

导师名单不能单独证明某人是教师。Bhawna Mukhija 出现在导师名单里，天文成员页将此人标为博士后，因此不收。

## 首版必须有的字段

身份、职称、研究方向、官方链接、来源证据。简介、代表作、照片、英文简介可以后补。没有这些，页面留空，不编造。

名单页没有方向时，以个人页的「研究方向」栏目为准。个人页也没有时，才使用导师名单或任职原文，并在证据里说明。
