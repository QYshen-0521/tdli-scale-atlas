# Q4. 外部数据源：AMiner 与天文师资目录

调研日期：2026-10-15。仅调研，未接 API、未改站点逻辑。

## 一句话

- **TDLI 现役导师「谁在图上」**：仍以研究所官网名录为准。
- **论文 / 方向自动更新**：优先 **OpenAlex**（CC0）+ **ORCID** 对齐；ADS 适合人工校对，不宜整库镜像。
- **AMiner**：适合中文侧查人、追新文，**不宜作公网站主库或批量转载画像**（协议与肖像风险）。
- **全球扩展**：Warwick / AstroWeb / ROR 定机构 → OpenAlex 拉人；IAU 作「职业天文」先验。未见「全世界天文老师已画在 L–M 上」的现成同等 dataset。

## AMiner（https://www.aminer.cn）

| 项 | 结论 |
| --- | --- |
| API | 有开放平台；学者搜索等部分免费，画像/详情/关系等多为付费 |
| 中文覆盖 | 国内学者检索强；不是官方在职名录 |
| 比官网新？ | 论文流通常新于手抄官网；单位/在职仍可能错 |
| 公网站转载 | 风险高：协议限制站外使用与镜像；头像更敏感 |
| 对 L–M 图 | 可人工校对、发现漏人；不宜批量同步进仓库 |

## 候选源（精简）

| 名称 | 规模约 | 适配 |
| --- | --- | --- |
| OpenAlex | 全球作者海量；可按 topic 滤天文 | **论文层首选（CC0）**；无标准头像 |
| ORCID | 全球 ORCID | 身份主键；不单独定导师名单 |
| ROR | 全球机构 | 机构主键（全球扩展必用，CC0） |
| NASA ADS | 天文文献金标准 | 查询校对；条款限制系统爬取/再分发 |
| IAU Directory | ~1.25 万活跃会员 | 补全职业天文身份；无论文流/主题图 |
| Warwick Astronomy Map | ~748–753 所机构 | 全球机构种子；无个人 |
| AstroWeb (CDS) | 数百系所等 | 偏旧；机构种子备份 |
| AAS / EAS 会员目录 | 会员制 | 登录墙；不适合公网站主源 |
| Semantic Scholar | 大学者图 | 次选；优先 OpenAlex |
| Wikidata / HF Astronomer DB | ~1.2 万「天文学家」 | 历史人物多；现役不全 |
| 各台站/系所导师页 | 按单位 | 中国侧「谁在职」真相源（与李所官网同类） |

## 推荐架构（不实施）

**仅 TDLI：** 官网定人 → OpenAlex 更新论文/主题 → ORCID 对齐 → ADS/AMiner 人工校对 → 头像仍用官网或本人提供。

**全球以后：** Warwick+ROR 机构清单 → OpenAlex 按机构/topic 候选人 → IAU 先验 → 薄数据层（ROR / OpenAlex Author / ORCID）；需换渲染与编目，不能硬扩现有手写 JSON。

## 排序

1. 在职真相：研究所官网  
2. 论文自动更新：OpenAlex  
3. 人 ID：ORCID  
4. 文献深度校对：ADS（查询）  
5. 中文发现漏人：AMiner（人工）  
6. 全球机构种子：Warwick → ROR  
7. 职业天文先验：IAU  

避免：会员墙目录当主源、AstroWeb 当现役师资库、未授权转载 AMiner 画像、整站镜像 ADS。
