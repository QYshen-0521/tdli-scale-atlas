# Q2. 色块的形状是怎么定的？

**短答：** 不是论文统计，也不是选择函数或误差棒。是编者按公开研究方向，在对数坐标里手画的包络。近方、椭圆、不规则，是为了让那句话能落在图上，同时少挡住别的天体。

`data/PLACEMENTS.md` 写明：「区域是包络，用来告诉读者工作大致在这一带，不是选择函数。」`data/README.md` 写明：这些区域是根据公开研究方向做的判断，不是导师本人画的。代码里没有从论文、引用或巡天选择函数计算 `regions` 的步骤。`src/content.ts` 只是读入 `data/mentors.json`。

## 代码里有哪几种形状

`src/types.ts` 允许三种，绘制在 `src/components/Chart.tsx` 与 `src/components/MiniMap.tsx`：

| `shape` | 字段 | 图上怎么画 | 用了几次 |
| --- | --- | --- | --- |
| `ellipse` | `cx, cy, rx, ry`（单位是十倍，dex） | 椭圆。横半径乘长度轴的像素比例，纵半径乘质量轴的 | 11 |
| `rect` | `logL0, logL1, logM0, logM1` | 圆角矩形，盖住这一段尺度和这一段质量 | 4 |
| `polygon` | `points: [logL, logM][]` | 折线闭合 | 1（只有水野阳介的喷流那一块） |

`coverage` 不改变形状，只改变填色和能否点在内部：

- `focused`：填充较实（透明度基数 0.12）
- `wide`：更淡（0.055）。景益鹏、冯发波、王界双
- `broad`：几乎透明（0.035），虚线，点击打在轮廓上而不是填色上。只有赖东

头像不放在区域的几何中心。`anchor` 是单独写的点，常常在边缘；`leader` 再拉一条线到区域里面，避免印章叠在天体照片上。这些坐标同样是手填的。

画面把横轴拉宽之后，dex 上的圆会变成偏宽的椭圆。这是绘制比例，不是当初选「椭圆还是方块」的理由。形状是在数据坐标里定的。

## 每人一块，对应哪句话

数字是大约的 dex，用来对准 `PLACEMENTS.md` 里的那句范围，没有拟合。

| 导师 | 形状 | 实际理由 |
| --- | --- | --- |
| 赖东 | 一个横宽的矩形，虚线 | 从行星质量和中子星半径一直到亚秒差距双星盘、约 10⁹ M☉ 的双黑洞。范围盖住太阳和白矮星，所以不填实色。轴子-光子传播不画进去 |
| 景益鹏 | 一个偏大的椭圆 | 星系到星系团：大约 kpc 到几十 Mpc，晕质量从矮星系到富团。不到可观测宇宙，所以椭圆停在张鹏杰那一块的左边 |
| 杨小虎 | 更小的椭圆 | 星系群和星系团，约 0.2–2 Mpc、10¹²–10¹⁵ M☉。比景益鹏紧，所以 rx、ry 更小 |
| 张鹏杰 | 贴着右上角的椭圆 | 沿宇宙平均密度，从大约 Gpc 到可观测宇宙。纵轴是那个体积里的折合质能。椭圆中心在 log L ≈ 26、log M ≈ 53，右缘略超出数据右界 10²⁷ m（约到 10^27.1），这是手画时越界了一点，不是测量 |
| 祖颖 | 椭圆 | 星系到星系群，对应他把恒星成分映射到暗晕的尺度。暗能量不画成区域 |
| 冯发波 | 一条横的矩形 | 尺度从行星半径拉到奥尔特云（约 10⁴–10⁵ AU），质量停在地球到木星，所以是扁的带，不是一团。主页写了星系动力学，代表论文不在那里，矩形没有拉到银河系 |
| 水野阳介 | 小椭圆 + 六边形 | 椭圆是中子星和恒星级黑洞的引擎。多边形包住人马座 A*、M87* 的视界和大约两个数量级的内喷流。更外的喷流会横切星系区，所以没有拉成一条长带，顶点是手写的 |
| 潘震 | 两个椭圆 | 一块是双中子星，一块是活动星系核附近的极端质量比旋近。原初引力波背景没有坐标 |
| 谭先瑜 | 小椭圆 | 木星到褐矮星的半径和质量。大气标高不另占一块 |
| 唐梦涛 | 小椭圆 | 高红移星系，约 kpc、10⁸–10¹⁰ M☉ |
| Masahiro Ogihara | 矩形 | 行星加上大约 100 AU 的原行星盘。和冯发波的带重叠，用颜色和锚点分开 |
| Darius Modirrousta-Galian | 很小的椭圆 | 超级地球和亚海王星：约 1–4 R⊕、1–20 M⊕。这是「理论与观测里常见的范围」，不是某一篇的拟合协方差 |
| 郑宪忠 | 椭圆 | 成员星系到红移约 2 的原星系团核心。JUST 望远镜不占坐标 |
| 王界双 | 一条扁矩形，填充很淡 | 质量停在中子星到恒星级黑洞，尺度从约 10 km 到遗迹的秒差距。淡，是为了不涂掉太阳 |

不在图上的 9 人（周浩、刘江来、周宁、徐东莲、何小刚、葛韶锋、张杰、吴益鹏、易龙卿）`regions` 为空。理由在 `PLACEMENTS.md`：信使粒子、GeV 质量、或实验室尺度小于图的左缘（约 1 km）。这是「不画」的编辑决定，不是算出来的零面积。

## 和「系统计算」差在哪里

没有做过这些事：

- 没有把论文里的质量、半径误差收成协方差椭圆
- 没有用巡天的选择函数或模拟的占据分布当边界
- 没有聚类算法决定谁用椭圆、谁用多边形
- 导师没有审过这些顶点

所以近方的矩形表示「这一段尺度 × 这一段质量都算」，椭圆表示「围绕一个典型尺度摊开」，多边形只在椭圆会误伤邻近天体时用过一次。三者都是示意。
