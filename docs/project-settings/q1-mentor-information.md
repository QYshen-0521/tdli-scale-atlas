# Q1. 收录的导师信息是不是最新、正确的？

2026-10-15 之后，范围和逐人去向以 [收录规则](inclusion-policy.md) 和 `data/coverage/ledger.json` 为准。下面这些百分比是当时的主观判断，不再当作覆盖率。

**短答：** 写进图里的这 23 人，姓名和「人还在李政道研究所、大致在哪个研究部」这件事，和 2026-10-14 打开的官网对得上，把握较高。把它当成「此刻官网的完整导师名录」或「每篇代表论文都已核对过」则不成立。下面把把握拆开，并写明没核对的部分。

## 把握（分开说）

| 范围 | 把握 | 含义 |
| --- | --- | --- |
| 已收录 23 人的姓名、研究部、公开邮箱 | 约 **85%** | 与当天的研究部成员页、研究生导师名单对照过；邮箱与名单上的地址一致 |
| 已收录者的现职头衔（讲席、长聘、青年学者、主任等） | 约 **75%** | 成员页的头衔层级和抽查的三份个人主页一致；没有把 23 份主页逐份打开 |
| 代表性论文就是主页上的当前列表 | 约 **55%** | 只逐条对过两个人。有的列表是子集，并且会落后于主页上新添的一篇 |
| 荣誉、校外奖项、院士身份 | 约 **60%** | 来自主页上的荣誉栏，这次没有拿中国科学院、美国天文学会等外部名录再核一遍 |
| 「李所天文相关导师已经收全」 | 约 **40%** | 项目本来就是子集。按它自己写的标准，也还有几位写着中微子、暗物质或粒子天体物理的导师没进来 |

这些百分比不是统计置信区间，是对「如果现在再核一遍，会不会发现实质错误」的主观判断。

- 天文与天体物理研究部成员页：<https://tdli.sjtu.edu.cn/research/astronomy-and-astrophysics-division/member>

## 已经能指出的偏差和缺口

这些不是猜测，是这次打开页面时看到的。

1. **张鹏杰不在研究生导师名单的 HTML 里。** 成员页和个人主页都在，头衔是「特聘学者（双聘）、研究部副主任」。JSON 写成「特聘学者、天文与天体物理研究部副主任」，少了「双聘」。主页荣誉还有 2016 年创新研究群体，JSON 没写。不能据此说他不是导师，只能说两份官网页面并不完全同一套字段。
2. **刘江来的论文不是主页的完整当前列表。** 主页代表作现包含 *Precise Xe136 Double Beta Decay Measurement in PandaX-4T…*, Phys. Rev. Lett. **136**, 162501 (2026)。JSON 停在 2024 年的太阳中微子那篇，另外还少了主页上更早的几篇合作论文。身份信息是新的，论文列表是有选择、而且偏旧的子集。
3. **粒子与核物理研究部里，写明做宇宙学、暗物质或中微子、但没有收进图的导师**（导师名单原文）：何红建（中微子、暗物质）、韩君（粒子天体物理）、向昕（TRIDENT、暗物质）、李数（暗物质探测）、Michael Ramsey-Musolf（核物理、宇宙学）、Yuichiro Nakai（粒子宇宙学）。季向东在名单上的方向是「粒子物理」，`data/PLACEMENTS.md` 写明故意不收。项目自述是只收「明确做暗物质、中微子天文或粒子天体物理」的人；上面几位已经符合这句字面，所以这是范围上的缺口，不是官网还没更新。
4. **天文成员页的研究员系列大多没有页面：** 葛绪雷、顾一舟、黄小军、姜海娇、孙清辉、杨楷、朱鹏飞。钱列加、盛政明在成员页上，README 写明用张杰、吴益鹏、易龙卿代表实验室高能量密度方向，不单独做页。博士后、工程师、行政助理按 README 不收。若问题是「成员页上的人是否都在」，答案是否。
5. **Masahiro Ogihara、Darius Modirrousta-Galian** 没有中文姓名。这是主页当时就没有，不是漏译。
6. **王界双、葛韶锋** 的论文不是从一份短列表抄的，是从主页给出的 Inspire 里挑的。有没有漏掉他们更看重的工作，没有问过本人。
7. **景益鹏** 的代表论文偏近年；更早的经典工作没有补，README 已说明。这次没有打开他的主页复核是否又更新了列表。
8. **外部事实没有在这次复查里重做：** 赖东 2024 年 AAS Dirk Brouwer 奖、景益鹏的院士身份、各篇 DOI 是否都能打开、作者排序、肖像是否仍是主页上的那一张。肖像版权仍属原机构或拍摄者，不是知识共享。

## 没有核对的

- 其余约 20 份个人主页没有在写这份说明时重新打开
- 没有用 Inspire / ADS 对 23 人做作者消歧，也没有核对通讯作者
- 天体坐标是另一套数据（`data/PLACEMENTS.md`），很多是量级，不在「导师信息是否最新」里
- 色块位置不是导师提供的，见 Q2

## 结论怎么用

对外介绍时可以说：人名和单位来自李政道研究所官网 2026 年 10 月 14 日的页面，头衔大体同时。不要说论文列表与荣誉已经与主页逐条同步，也不要说这是研究部或导师名单的全表。若要提高把握，下一步是把 23 份主页的代表论文和荣誉再对一遍，并明确写出粒子部那几位是「未收」还是「漏收」。这次没有改数据。
