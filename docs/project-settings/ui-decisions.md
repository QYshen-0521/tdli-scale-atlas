# 界面上的三项决定

对应这次改动的三件事。实现分别在 `src/lib/motion.ts`、`src/styles.css`、`src/components/DetailPage.tsx`、`src/lib/coords.ts`。

## 1. 飞行动画：速度改为原来的 2/3

头像从星图飞进详情、再飞回去，之前是 700ms，显得太快。速度改为原来的 **2/3**，时长因此变成原来的 **3/2**：

700ms × 3/2 = **1050ms**

同一比例用在进出场成对的时间上，不单改飞入：

- View Transitions 里头像组（`mentor-flight`）的时长
- 根页面交叉淡出、淡入
- 不支持 View Transitions 时的 FLIP 补间
- 不支持 View Transitions 时，详情页与星图上伴随出现的淡入（返回按钮、姓名、位置框、正文、图面）

悬停时名字的 140ms，以及「重置视野」的 520ms，不属于这次进出场，没有改。系统要求减少动效时，这些过渡仍然关掉。

## 2. 详情页：「在图上的位置」进页即完整可见

原先位置框在大标题下面，缩略图又按栏宽画成正方形，视口里往往只看得到上半。现在：

- 页面用到更靠左右边缘的宽度（内容最大约 1600px，左右各留约 8px，不再卡在 1080px 居中）
- 位置框与姓名并排，从页头就开始，不再被整段标题压到折线以下
- 位置框内边距略收紧
- 缩略图的边长取「栏宽」和「视口高度减去标题与说明所占高度」里较小的那个，说明文字留在图下方，整块框落在首屏里

窄屏改成上下排，位置框紧跟姓名、排在长正文之前，缩略图同样按视口高度封顶。

## 3. 图框 1:1，但不把横轴加到 10⁴⁰ m

曾经为了让横轴和纵轴都是 37 个数量级，把 `logL` 从 `[3, 27]` 改成 `[3, 40]`。右缘因此空着，可观测宇宙不再贴着数据范围的右上角。这一做法已经撤回。

数据范围恢复为：

- L：10³–10²⁷ m（24 个数量级）
- M：10¹⁸–10⁵⁵ kg（37 个数量级）

可观测宇宙仍在 log₁₀ L ≈ 26.64、log₁₀ M ≈ 54.48，也就是这块数据的右上角。

正方形只发生在画面上：质量轴每十倍的像素记为 `k`，长度轴每十倍的像素是 `k × 37/24`。数据矩形的宽和高因此相等。缩放时两个方向一起变，正方形保持。椭圆的横半径用长度轴的比例、纵半径用质量轴的比例，所以色块跟着轴一起被拉开，而不是在数据里多画十几个空的数量级。
